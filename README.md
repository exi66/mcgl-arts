# mcgl-arts

Веб-галерея пиксель-артов игрового проекта [Minecraft Galaxy](https://minecraft-galaxy.ru/ru/): поиск по названию и
автору, подробный просмотр. Сайт: https://exi66.github.io/mcgl-arts/

## Как добавить картину

Положите файл в папку автора и запушьте в `main` — сайт обновится сам:

```
src/assets/artworks/<Автор>/<Название>.png
```

- Имя папки — ник автора, имя файла без расширения — название картины.
- Картины без автора кладутся в `src/assets/artworks/default/`.
- Поддерживаются `.png`, `.jpg`, `.jpeg`.
- Адрес картины на сайте — `artworks/<Автор>/<Название>.png`, на него можно ссылаться с форума. Не переименовывайте
  уже опубликованные файлы: ссылки сломаются.

## Поиск

Текст ищется в названии и авторе. Операторы: `author:TGeinz`, `name:"Ночь в майнкрафте"`, можно вместе с текстом:
`author:TGeinz дракон`. Запрос сохраняется в адресе (`?q=`), ссылкой с поиском можно поделиться. Ctrl+F — фокус на
поиск.

## Разработка

```
pnpm install
pnpm dev          # dev-сервер
pnpm build        # сборка в dist/
pnpm test         # тесты
pnpm lint         # oxlint
pnpm format       # prettier
pnpm typecheck    # tsc
```

Сделан на [шаблоне exi66/starter](https://github.com/exi66/starter). Изменения кода публикуются тегом:
`git tag v1.0.0 && git push --tags`.
