# mcgl-arts

Веб-галерея пиксель-артов игрового проекта [Minecraft Galaxy](https://minecraft-galaxy.ru/ru/). Поддерживает поиск по названию и автору и подробный просмотр.

## Разработка

```sh
npm install
npm run dev     # локальный сервер
npm run lint    # проверка ESLint
npm run build   # сборка в dist/
```

Сайт собирается и публикуется на GitHub Pages автоматически при пуше в `main`.

## Как добавить картину

Положите файл в папку автора:

```
src/assets/artworks/<Автор>/<Название>.png
```

- Имя папки — ник автора, имя файла без расширения — название картины.
- Картины без автора кладутся в `src/assets/artworks/default/`.
- Поддерживаются `.png`, `.jpg`, `.jpeg`.
